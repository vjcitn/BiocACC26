## BiocACC26 - a workspace for discussing Bioc/AnVIL symbiosis

The content of this workspace is governed in part by the
github repository `https://github.com/vjcitn/BiocACC26`, and in part
by operations within AnVIL that populate the 'DATA' component of the
workspace.

The workspace `Bioconductor-package-BiocACC26` was created by an
`AnVIL` package function call:
```
as_workspace("BiocACC26", "landmarkanvil2", dry.run = FALSE, 
    create = TRUE, type = "rmd", use_readme = TRUE)
```

As content is modified in the GitHub repo, the workspace can be updated
with `update=TRUE` substituted for the `create` setting in the
command above.
